# DevFlow

DevFlow is a premium developer workflow landing page created for the Acdyon Technologies Frontend Challenge.

## Tech Stack

- React
- Vite
- JavaScript
- CSS
- Lucide React

## Features

- Responsive navigation
- Hero section
- Product dashboard preview
- Feature section
- Workflow section
- Responsive mobile layout
- Hover interactions
- Responsive design for 390px and 1440px

## Run Locally

```bash
npm install
npm run dev
